# TP_Generiques

## Exercice 1 : Classe générique Triplet<T>

<img width="438" height="285" alt="image" src="https://github.com/user-attachments/assets/c015b241-eea8-49ce-80cd-82806c633bfc" />


Dans cet exercice, nous avons créé une classe générique `Triplet<T>` qui permet de stocker trois éléments du même type. Nous avons utilisé un constructeur pour initialiser les trois éléments et des méthodes getters pour accéder à leurs valeurs. La classe de test permet de créer des triplets de type `Integer` et `String` et d'afficher leurs contenus.

## Exercice 2 : Classe générique TripletH<A, B, C>

<img width="438" height="285" alt="image" src="https://github.com/user-attachments/assets/2a237b07-9afa-4365-84fa-2647fc4b2612" />


Dans cet exercice, nous avons créé une classe générique `TripletH<A, B, C>` qui permet de stocker trois éléments de types différents. Chaque élément possède son propre paramètre de type. Nous avons ajouté un constructeur, des getters et une méthode d'affichage. La classe de test permet de vérifier le fonctionnement avec plusieurs combinaisons de types.

## Exercice 3 : Les bornes génériques

<img width="870" height="259" alt="image" src="https://github.com/user-attachments/assets/d6ae30b8-fb54-42e5-96d4-701957111185" />



Dans cet exercice complémentaire, nous avons utilisé les bornes génériques avec `<? extends Personne>`. Nous avons créé une classe `Personne` et deux classes dérivées : `Etudiant` et `Enseignant`. Une méthode permet d'afficher une liste contenant des objets de type `Personne` ou de ses sous-classes. Cet exercice permet de comprendre l'utilisation des bornes supérieures dans les génériques Java.
